# EasyAPI 产品营销上下文

供 seo-audit / ai-seo / schema / product-marketing 等 Skill 读取的定位上下文。
由 2026-11 全站 SEO 审计（定位错位纠偏）时建立，站点信息变更时同步更新。

## 一句话定位

免费、无需注册的在线小工具箱 + 开放 API 聚合平台：文案语录、随机数据生成、
生活查询、编码生成四类工具，每个工具既有网页版也有可直接调用的接口。

## 目标用户

1. 开发者/独立开发者：要测试数据、占位图、文案类接口，不想为小需求接重型服务
2. 普通用户/学生：日常查询（节假日、邮编、区号、身份证解析）与娱乐（每日一言、
   毒鸡汤、疯狂星期四文案）
3. 内容创作者：找文案素材与灵感

## 核心价值

- 免费无鉴权：公开接口不需要 API Key，按 IP 限流（30 次/60 秒）
- 网页 + API 双形态：点开即用，也能 curl / HTTP 直接调用
- 统一响应壳 + `format=text` 纯文本直出，接入成本低
- 中文文档与国内场景数据（节假日、车牌、邮编、身份证）

## 关键词族（SEO / AEO 用）

- 品类词：免费 API、在线工具、API 聚合平台、开发者工具箱
- 工具词：BMI 计算器、二维码生成器、随机图片 API、每日一言 API、身份证查询、
  IP 归属地查询、条形码生成、Tailwind 色板、歇后语大全、土味情话、舔狗日记、
  疯狂星期四文案、密码强度检测
- 场景词：测试数据生成、占位图、文案素材、接口文档
